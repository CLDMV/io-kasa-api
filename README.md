# @cldmv/io-kasa-api

Slothlet-based local-network API for TP-Link **Kasa** smart devices — plugs, switches, dimmers, bulbs, motion sensors.

The first release (**v0.1.0**) is being prepared on the [`release/0.1.0`](../../tree/release/0.1.0) branch. Open the PR there for the full README, source, and tests.
